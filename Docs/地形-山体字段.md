# 地形：山体字段（AoE2 方向）

> 状态：**山体字段、程序化山体高度、岩石材质、山体笔刷、A* 不可通行已实现**。
> 目标：你先设定整张图的基础高程，然后只圈出连续的山体区域；山体具体长什么样由生成器决定，不靠你雕刻。

## 1. 数据

- `MapData.mountain`：`PackedInt32Array`，每格 0=无 / 1=山体，和 `land / water / road / elevation` 平行保存；
- 旧地图没有这个字段时按 0 处理，载入时补零数组；
- 山体不改写陆地分类；山脚仍是原来的草地/道路；
- 山体 footprint 与基础高程随地图 `.tres` 保存；**山体的生成高度不存档**，载入时按 footprint 重新生成。

## 2. 编辑

- 左侧「陆地类型」面板末尾新增 **山体** 按钮；
- 左键绘制山体，右键擦除；
- 用草地/道路/水域笔刷重新画在同一格，会把山体挖掉（开路/开地）；
- 「地形视图」面板里有 **高程** 等级按钮 `1 / 2 / 3 / +`：点数字即切到高程笔刷，左键把笔刷区域整格设成该级、右键恢复 1 级；`+` 新增下一级（上限 32 级）。高程与陆地/水/道路互不覆盖；
- 抬升/压低/平滑/展平雕刻已移除：高程只做整级设定；山峰高度 = 该格高程 + 生成器起伏，所以用高程笔刷抬高山体格会整体抬高这座山，但山峰形状仍由生成器决定。

高程改动会立即刷新 45° 预览；没有山体时只重算脏区，有山体时按新的山体基础高程重建整张山体高度。

## 3. 程序化生成

`data/mountain_generator.gd`：

1. 从所有非山体格做多源 BFS，只得到每个山体格的“离山脚距离”（控制山脚缓升曲线）；
2. 用两道 `FastNoiseLite` 脊状噪声生成山脊/沟谷；
3. 山体高度 = **该格你画的高程** + 高度幅度 × 缓升曲线 × 脊状起伏；
   - **峰顶是相对高度**：山体所在高程为 1 级时最高为 `max+1`，高程为 3 级时最高为 `max+3`；没有绝对高度封顶（只受 8 位高程存储 63.75 级限制）；
   - 缓升曲线用指数收顶（`1 - exp(-d / RIM_CELLS)`，默认展开 6 格），山脚不是垂直陡壁；
   - 高度幅度默认 5～8 级，整段山脊约 4～6 级，能看出是山体但不会把后方挡死；
4. 结果写进运行时的合成高度场（不写回 `map.elevation`），同一 footprint 结果固定（固定种子）。

山体轮廓、峰谷、脊线都由 footprint 和噪声决定，不需要你决定。

## 4. 渲染

- `MapRuntime` 把 `mountain` 遮罩上传为 `u_mountain`，同时用 `MountainGenerator` 的合成高度生成 `u_elev / u_elev_smooth`；
- `terrain.gdshader` 在山体格覆盖独立板岩材质：块面、层理、裂缝、山脚压暗折痕；
- 山体材质和草地/沙地/道路/水的笔触明确分开；山脚是硬边 + 折痕；
- 山体 footprint 变化时，45° 小预览整图重建，重新生成山高。

## 5. 通行

- `MapRuntime._raw_cost()` 对山体格直接返回 0，A* 不可通行；
- 可行走路径 = 地面/道路/水域中非山体的格子，和视觉上的山体边界一致。

## 6. 使用流程（AoE2 式）

1. 先设定整张图的基础高程：用「高程」1/2/3/+ 笔刷铺整级高度（也可来自外部高度图/现有地图数据）；
2. 用山体笔刷圈出一块连续山体 footprint（可以是不规则边缘）；
3. 山体的高度、峰谷、脊线自动生成，玩家不能进入；
4. 山脚用草地/道路画可行走路径，栅栏/建筑贴着山脚放。

## 7. 已知边界 / 下一步

- 山体目前是单一类型（0/1）；要分岩石/雪山/森林山，可扩展值并按值切换材质；
- 生成参数（幅度 5～8 级、展开 6 格、频率、种子）目前是常量；需要时再暴露成地图级参数；
- 若要完全复刻 AoE2 的贴图崖壁 tile，下一步是给山体/高程边界加模块化崖壁贴图，而不是继续加高度场细节。

## 8. 代码落点

| 文件 | 作用 |
|---|---|
| `data/map_data.gd` | `mountain` 字段、读写/建图/改尺寸/旧图补零 |
| `data/mountain_generator.gd` | 距离场 + 脊状噪声生成山体高度 |
| `data/grid_defs.gd` | 山体俯视颜色、图层名称 |
| `editor/grid_view.gd` | 俯视图山体色块、道路/流向在山体上隐藏 |
| `editor/grid_tools.gd/.tscn` | “山体”笔刷按钮；地形面板的高程 1/2/3/+ 等级笔刷 |
| `editor/main.gd` | 山体绘制/擦除、地面笔刷挖山、高程整级绘制、整图小预览重建、撤销快照 |
| `runtime/map_runtime.gd` | 合成高度场、高程脏区/山体重建、山体遮罩纹理、A* 阻挡、`height_max()` |
| `runtime/terrain.gdshader` | 独立板岩山体材质与山脚折痕 |
