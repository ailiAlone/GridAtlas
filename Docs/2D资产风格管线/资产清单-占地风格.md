1. **P0 贫村民居/棚屋（16 个）**：`bld_poor_cottage_*` 5 个 + `bld_house_thatch_01` + `bld_poor_*` 10 个（石碾为 `prop_stone_mill`）。先做 3×2 单间茅草屋样片（当前 `redraw_3x2/`），验收后同流程批量。

3. **P2 田块/栅栏/门（5 个）**：稻麦田、菜园、木栅栏、木栅栏门、荆条篱笆门。田块走俯视地块管线，栅栏走扁平立牌。
4. **P3 树/道具（10 个）**：7 种树 + 水井、草垛、石碾。全部重生成；现有素材作为风格参考，保证和村庄同一套色盘/描边。
