# 45° 立牌重绘规格（地基 / 高度）

> **2026-11-04 更新：项目相机已改回 45°。** 30° 只是中间实验；本文的 45° 地基/高度数值仍是当前目标，
> 但 AI 直出会把底面压到 30°，所以导入时仍按 1.3 做垂直修正。详见
> [资产生成流程-几何锁定版.md](资产生成流程-几何锁定版.md) 第 12 节。
>
> 结论先说：**偏差大的素材必须重绘/重新生成，不能靠导入页的高度滑杆硬拉。**
> 三维锚定 + 高度拉伸只能做小幅位置/高度校正；大幅改变会按地基折线扭曲屋顶和墙体。
> 本文是重绘时的几何、风格和验收规范。

## 1. 为什么不能继续用高度滑杆

- 三个地基锚点固定后，`anchor_height` 以“左/前/右按 x 排序后的地基折线”为基准做垂直拉伸；
- 折线是 V 形，拉伸越往上越跟着坡度走，于是屋顶/上边缘会变尖、墙体比例失真；
- 这是数学结果，不是参数没调好。要同时做到“三个地基点不动 + 上边缘水平/比例正确”，二维拉伸做不到；
- 素材本身的地基坡比和目标相机不一致时，**即使 `anchor_height = 1.0`，三点仿射已经在纵向拉伸整张图**。所以正解是让素材一开始就按目标 45° 相机绘制。

## 2. 目标几何

固定相机：yaw 135°、pitch 45°、正交；立牌竖直、贴图不按俯角压扁。

占地 W×H 的地面菱形四角：

```text
back  (0,0)      right (W,0)
left  (0,H)      front (W,H)
```

屏幕投影（格）：

```text
screen(x,y) = ((x-y) * 0.7071, (x+y) * 0.5)
```

地基是 W×H 的**平行四边形**；左前边和右前边不是对称的 V，非正方形占地的左/右角高度不同：

```text
地基底边宽度 = 0.7071 * (W + H)
左坡比 = (前角 y - 左角 y) / 底边宽度 = 0.7071 * W / (W + H)
右坡比 = (前角 y - 右角 y) / 底边宽度 = 0.7071 * H / (W + H)
```

| 占地 | 左坡比 | 右坡比 | 参考图 |
|---|---|---|---|
| 5×4 | 0.393 | 0.314 | `参考/5x4-45度-标注.png` |
| 3×4 | 0.303 | 0.404 | `参考/3x4-45度-标注.png` |
| 3×3 | 0.354 | 0.354 | `参考/3x3-45度-标注.png` |
| 4×3 | 0.404 | 0.303 | `参考/4x3-45度-标注.png` |
| 3×2 | 0.424 | 0.283 | `参考/3x2-45度-标注.png` |
| 2×2 | 0.354 | 0.354 | `参考/2x2-45度-标注.png` |

参考图里：

- **蓝框** = 占地地基平行四边形；浅蓝网格 = 每个占地格；
- **绿色点** = 左/前/右三个锚点；非正方形占地时左/右点**不在同一高度**；
- **黄色框** = 目标高度框（按 `资产清单-占地风格.md`：5×4 6.4、4×3 5.6、3×3 5.0、3×2 4.4、2×2 3.6 格）；
  立牌是竖直 billboard，高度按屏幕格 1:1 画，**不乘 cos(45°)**；
- 黄色刻度 = 从地基往上每 1 格；
- 透明版用于描图/垫图；标注版用于看规格。

> 当前 AI 素材实测：酒肆（3×3）左/右坡约 0.24，目标 0.354（扁约 1.5×）；石基茅草屋（3×4）左坡约 0.14–0.16、右坡约 0.19–0.21，目标 0.303/0.404（扁近 2×）。这就是为什么怎么调高度都不对。

## 3. 风格要求（贫村建筑）

```text
16-bit pixel art game asset, Chinese ancient poor village, [建筑描述],
[材质与细节], dark brown pixel outlines, muted earthy palette, olive and warm brown,
front-facing three-quarter view, vertical walls, orthographic,
single building centered, full building visible, isolated cutout on plain pure white background,
no ground plane, no grass, no dirt base, no cast shadow, no people, no animals,
no text, no watermark, crisp pixels, limited 12-color palette
```

硬性要求：

- **不要写 isometric / 45-degree downward camera**：实测会把模型带到等距俯视 + 烤死的地面底座；
- 地基必须是**建筑自己的底面**，不是草地/泥地/石台底座；
- 地基是 W×H 的平行四边形；非正方形占地时左/右角高度不同，左/右坡按上表；
- 墙面竖直，贴图是立牌，不是等距方块；
- 透明 PNG，无烘焙阴影（阴影由引擎加）；
- 与 `贫户茅草屋.png`、`_blacksminth.png` 并排风格一致。

## 4. 重绘路线

### A. 手绘/描图（推荐，当前工具链最可靠）

1. 在绘图软件里打开对应占地的 `参考.png`（透明版），锁定为底层；
2. 把建筑地基的**左/前/右三个角**对准绿色点，脚底网格对准蓝框；
3. 屋顶控制在黄色目标高度框以内，墙面保持竖直；
4. 导出透明 PNG（不要地面底座/投影）；
5. 导入 GridAtlas，三点锚定把三个锚点放到参考图三个绿点位置，`anchor_height` 保持 `1.0`；
6. 切 45° 渲染验收。

### B. 3D blockout + 贴图/图生图

1. 按占地 W×H 和目标高度做最简单的 3D 盒子（底面 = 占地菱形，竖直墙）；
2. 渲染正面 45°（正交、相机 yaw 135°、pitch 45°）作为结构参考；
3. 用支持 **ControlNet / img2img** 的本地模型（或人工）在结构参考上上色；
4. 当前 MiniMax 文生图和本机 ComfyUI 的 MiniMax 节点**没有 ControlNet/参考图控制**，不能直接走这条；需要另装本地 SD/ControlNet 或人工绘制。

### C. 文生图只做灵感

- 可以继续用 MiniMax 生成草图，但**只取屋顶/材质/配色**；
- 地基必须回到参考图重画；不要接受带地面底座的图；
- 本次试绘的 4 张 3×4 石基茅草屋已全部因等距/地面底座判为不合格，存放于
  `Assets/Generated/GridAtlas/minimax_poor/redraw/raw/`，不进入 catalog。

## 5. 验收清单

- [ ] 透明 PNG，alpha 正常；无地面/草地/泥地底座，无烘焙投影，无文字水印。
- [ ] 建筑地基是 W×H 的平行四边形；左/右坡与目标相差 ≤ 10%；左/右角高度按参考图，不要求同高。
- [ ] 墙面竖直，不是等距俯视；屋顶没有因相机角度变成俯视大平面。
- [ ] 三点锚定后，左/前/右锚点贴住占地三个角；`anchor_height` 在 0.95–1.05。
- [ ] 45° 渲染无悬空/穿地；阴影和遮挡正常。
- [ ] 与同村其他建筑并排，屋顶/描边/饱和度同一家族。

## 6. 当前素材优先级

1. **石基茅草屋 `bld_poor_cottage_stone_base`（3×4）**：偏差最大，作为第一张试绘；
2. 其余 3×4 民居（`timber` / `dilapidated`）、4×3 带披屋；
3. 酒肆（3×3）等偏差中等、但仍超过 15% 的资产；
4. 偏差 ≤ 10% 的资产可以继续用三点锚定 + 小幅高度，不必重绘。

## 7. 导入页的高度滑杆怎么用

- 重绘后 `anchor_height` 应该接近 `1.0`；
- 只建议 ±15% 的小幅修正（0.85–1.15）；超出时导入页会提示“建议重绘”；
- 大幅压缩/拉高仍然会按 V 形地基变形，不能替代重绘。

### 8.3 火山引擎 Seedream 试绘（2026-11-03）

- 模型：`doubao-seedream-5-0-flash-260915`（Endpoint `ep-20261030164243-twzkz`），图生图；
- 参考图：手绘结构立牌 + 旧版石基茅草屋风格图；另做了一版“线稿上色”参考；
- 结果：**屋顶、山墙、竖墙、门窗、木构和整体轮廓保留得很好**，像素风/材质明显更接近现有素材；
- 但模型把地基压成了**对称浅菱形**：实测左坡约 0.15、右坡约 0.19，目标是 0.303 / 0.404；地基被压平约 2×；
- 因此它仍然不能直接作为最终资产：三点锚定会把这版重新纵向拉伸，回到之前的问题；
- 文件：
  - `Assets/Generated/GridAtlas/redraw_seedream/raw/seed5105_lineart.png`（线稿上色，结构最好）
  - `Assets/Generated/GridAtlas/redraw_seedream/raw/seed5103_warm.png`（暖茅草）
  - `Assets/Generated/GridAtlas/redraw_seedream/raw/seed5101_single.png`、`seed5102_style.png`
- 预览：线稿上色 · 暖茅草
- 结论：Seedream 能解决**风格/细节**，但不能可靠保留**地基坡比**；地基仍需要四点透视校正或人工/3D 重绘。
