# 静态资产生成流程（几何锁定版）

> 目标：批量生成能直接放进当前 **45°** 地图、**不显得突兀**的建筑/道具。
> 核心原则：**几何由模板锁定，AI 只负责风格/材质。**
> 适用：GridAtlas 的 45° 立牌静态资源（建筑、棚屋、门、栅栏、道具）。
> 全量 39 个资产的名称 / 风格 / 预计占地 / 管线 / 优先级见 [资产清单-占地风格.md](资产清单-占地风格.md)。

## 0. 先记住三条结论

1. **纯文生图不能作为最终资产**。MiniMax 17 张、Seedream 4 张实测：模型会把建筑画成等距/3D，或把地基压成对称浅菱形；提示词、线稿、参考图都改不了这个先验。
2. **Seedream 5.0 Flash 是目前最好的“风格/材质”生成器**。给它线稿 + 旧素材风格图，它能保留屋顶、山墙、竖墙、门窗、木构，并把茅草/石基/木纹画得接近现有素材；但它仍会压平地基。
3. **地基/高度必须由参考/线稿保证**。AI 图不是几何真相；不要靠运行时三点锚定或高度拉伸硬对三个地基角。

## 1. 流程总览

```text
0. 选占地/高度/建筑类型
      ↓
1. 几何模板：参考图 + 线稿（或 3D blockout）
      ↓
2. Seedream 上色：线稿 + 旧素材风格图 → 3–4 张候选
      ↓
3. 纹理锁回：把 Seedream 纹理映射到精确线稿几何
      ↓
4. 去背/裁切/调色/描边 → final PNG
      ↓
5. 导入页：旧模式导入，手动调 `art_size` / `art_lift` / `art_offset`
      ↓
6. 地图 45° 验收：地基/高度/比例/风格/阴影
      ↓
7. 注册 StaticAssetDef + 放置 + 截图 + 文档
```

## 2. 阶段 0：定规格

每个资产先写死：

```text
footprint = W×H         # 3×2 / 3×3 / 4×3 / 5×4 / 2×2 / 1×1
target_height = 格数    # 立牌屏幕高度（1 格 = 1 格屏幕，不乘 cos）；3×2 茅草屋 3.8
category = building / gate / fence / prop / tree
style_ref = 同村 1–2 张已有素材
```

地基目标（固定 45° 相机）：

```text
screen(x,y) = ((x-y)*0.7071, (x+y)*0.5)
左坡比 = 0.7071*W/(W+H)
右坡比 = 0.7071*H/(W+H)
```

| 占地 | 左坡 | 右坡 |
|---|---|---|
| 5×4 | 0.393 | 0.314 |
| 3×4 | 0.303 | 0.404 |
| 3×3 | 0.354 | 0.354 |
| 4×3 | 0.404 | 0.303 |
| 3×2 | 0.424 | 0.283 |
| 2×2 | 0.354 | 0.354 |

使用 `参考/` 下对应占地的标注图/透明参考图；非正方形占地左/右角**不在同一高度**，不要按对称 V 画。
高度框按**屏幕高度 1:1** 画（立牌不按俯角压扁），不要乘 cos(45°)；具体数值见 `资产清单-占地风格.md`。

## 3. 阶段 1：几何模板

### 3.1 参考图

`Docs/2D资产风格管线/参考/` 已生成 2×2、2×3、3×2、3×3、3×4、4×3、4×4、5×4、7×8、8×6 的：

- `-标注.png`：看规格；
- `-参考.png`：透明底，垫在绘图软件里描图；
- 蓝框 = 地基平行四边形；绿点 = 左/前/右锚点；黄框 = 目标高度；黄刻度 = 每 1 格。

生成脚本：`Docs/2D资产风格管线/工具/gen_ref.py`。改占地/高度或新增尺寸时，改脚本底部的 `(W,H,height)` 列表后重跑即可。

### 3.2 线稿

每条建筑类型做一张**线稿**（黑线白底或透明底），必须包含：

- 地基平行四边形的四个角（左/前/右必须准确）；
- 竖墙、墙角、屋檐、山墙、屋脊；
- 门、窗、木构架、石基分界；
- 目标高度框内的屋顶/檐口。

线稿的用途：

- 给 Seedream 当“线稿上色”参考；
- 当纹理锁回的目标几何；
- 当导入页锚点的来源。

线稿可以是手绘，也可以是 3D blockout 的线框/边缘渲染。**不要用 AI 生成的图当几何真相。**

## 4. 阶段 2：Seedream 上色

### 4.1 模型与前置

- 模型：`doubao-seedream-5-0-flash-260915`
- Endpoint 以当前 profile 为准：

```bash
arkcli resources list --modality image --format json
arkcli resources resolve <ep-id> --format json
```

- 账号 TOS 未开通时，本地参考图必须加 `--inline-local`（图片可内联；视频/音频不行）。

### 4.2 命令模板

```bash
ARKCLI_NO_UPDATE_NOTIFIER=1 ARKCLI_CALLER_TYPE=ai_agent \
ARKCLI_CALLER_NAME=zcode ARKCLI_SKILL_NAME=arkcli-gen \
arkcli +gen \
  --model <image-ep> \
  --modality image \
  --input reference_image:@<线稿.png> \
  --input reference_image:@<同村风格参考.png> \
  --inline-local \
  --size 1536x2048 \
  --output-format png \
  --watermark=false \
  --optimize-prompt=false \
  --seed <seed> \
  --save-to "<输出目录>" \
  --format json --no-open \
  "<提示词>"
```

- 一次只出一张；用不同 `--seed` 生成 3–4 张候选。
- 输出默认白底；没有 `--background` 命令行参数，去背放在阶段 4。
- 输出文件默认 `ark-gen.png`，每次生成后立即改名（`<asset>_seed<seed>.png`）。

### 4.3 提示词模板

```text
Image 1 is a black-and-white lineart coloring page: color it as a detailed
16-bit pixel art game asset for a poor Chinese village.
Preserve the exact line positions and the exact parallelogram base in image 1;
do not move, symmetrize, or redraw the base corners; the left, front, and right
foundation corners must stay at the same positions.
Image 2 is only a surface style reference for thatch, stone, and timber textures,
dark brown outlines, and the muted earthy palette; do not copy image 2's base,
camera, or building proportions.
Make the thatch warm golden-brown sun-bleached straw, the foundation grey stone,
the walls mud and weathered timber.
Plain pure white background, no ground plane, no grass, no dirt, no stone platform,
no cast shadow, no people, no text, no watermark.
Do not turn it into an isometric or 3D render; keep the lineart's flat billboard
perspective.
```

要点：

- 明确“Image 1 = 结构/线稿，Image 2 = 只做材质风格”；
- 明确“不要移动/对称化地基角”；
- 明确“no ground plane / no platform / no cast shadow / not isometric”；
- 不要写“45-degree downward camera”“isometric”这类会触发 3D 先验的词；
- 茅草要写“warm golden-brown sun-bleached straw, not olive/green”。

### 4.4 Seedream 的已知限制

实测 Seedream 会保留屋顶、山墙、竖墙、门窗、木构，但会把地基压成**对称浅菱形**（3×4 实测约 0.15/0.19，目标 0.303/0.404）。所以 Seedream 图**不能直接进游戏**，必须进入阶段 3。

## 5. 阶段 3：纹理锁回（关键）

把 Seedream 的纹理/颜色映射到线稿的精确几何。两种做法：

### A. 2D 网格吸附（推荐，轻量）

1. Seedream 图先用 **AI 抠图 skill**（`remove-bg`）去背景，得到 RGBA 纹理源；不要用白底 flood fill 代替（边缘会留白边）；
2. 线稿作为目标图；RGBA Seedream 图作为纹理源；
3. 标记对应控制点（源图 ↔ 线稿）：
   - 地基四角：后、右、前、左；
   - 石基顶 / 墙底、墙顶/檐口：左、前、右；
   - 屋脊两端、山墙顶点；
   - 门、窗四角（可选）；
4. 按**可见面**分块，而不是全图 Delaunay（避免跨面三角形把屋顶贴到墙上）：
   - 石基左/右面、山墙矩形、山墙三角、右侧墙、右侧屋面；
   - 每块用 4 个控制点（或 3 个）做逐块仿射；三角形仿射用 PIL `Image.AFFINE` + 多边形 mask 合成；
5. 山墙三角在源图里通常被屋檐挡住：用山墙上部（门以上、檐以下）的一块墙面拉伸填充，**不要**把源图的屋檐/茅草贴到三角上；
6. 屋脊：源图的脊饰/瓦帽不要整块映射；脊线附近取茅草内侧，再用一条内侧脊带补出厚屋脊；
7. 只保留目标线稿的轮廓（alpha 用线稿的 alpha，向内收 1px），背景透明；
8. 把线稿的深色轮廓乘到纹理上（`0.45 + 0.55*lineart`），统一描边并盖住网格接缝；
9. 按同村 2–3 张旧素材做色盘校正：屋面降黄/加橙、墙面去灰、石基提亮；否则 AI 的亮黄茅草会明显跳色。

参考实现：`工具/mesh_lock_3x2.py`（3×2 单间茅草屋样片；控制点按资产改）。

> **适用性警告（2026-11-03）**：整图网格锁回要求源图和线稿的建筑构造一致（屋檐出挑、山墙遮挡关系、
> 像素密度）。如果线稿屋檐与墙齐平、山墙整块露出，而源图是有出檐的，山墙三角只能拉伸补，结果会
> 出现纸片感（3×2 样片已实测否决）。这类资产优先走“旧素材三点仿射重投影”，或改成材质贴图；
> 不要继续在整图锁回上堆控制点。

### B. 3D blockout + 纹理投影（质量最高，成本更高）

1. 按占地/高度做一个最简单的 3D 盒子 + 双坡屋顶；
2. 相机：yaw 135°、pitch 45°、正交；
3. 把 Seedream 的风格图投影/贴到 3D 表面，渲染正面；
4. 导出透明 PNG；
5. 适合批量做同一建筑类型的不同变体。

### 判定：什么时候可以跳过纹理锁回？

旧模式（左右侧 `art_lift`）只做垂直剪切，不能同时精确命中三个地基角；底面角度由参考/线稿保证，不要靠运行时硬拉。

- 实测旧 AI 素材差约 2×，Seedream 线稿版也差约 2× → 不能跳过；
- 超过 10% 继续用高度滑杆 = 屋顶/墙体按 V 形地基变形，必然突兀。

### 旧素材重投影（2026-11-03 起优先）

同一画风的旧贴图，如果**基座宽高比接近目标占地**，直接把旧图的三点地基锚到新占地，比整图锁回稳：

- 优点：画风/像素密度/光影不变，墙不歪、门窗不变形；只做一次整体仿射剪切；
- 适用：3×2 的 `bld_house_thatch_01`（基座宽高比约 3.5:1，目标 2.36:1，实测可接受）；
- 不适用：基座极扁的 AI 旧图（如 `bld_poor_cottage_single` 约 5.3:1），硬拉会明显歪，应保持大占地或重画；
- 验收看旧模式的 `art_size` / `art_lift` / `art_offset` + 地图 45° 视图。

## 6. 阶段 4：去背/裁切/统一风格

- Seedream 原图先去背：**优先用 AI 抠图 skill**（`remove-bg`，本地 ONNX），再用 1px alpha 腐蚀去掉白边；
- 锁回后的 final 用**线稿 alpha** 裁轮廓（向内收 1px），不依赖 AI 抠图的轮廓；
- 裁切到 alpha bbox，四周留 4px；
- 色盘：与同村 2–3 张素材并排，统一饱和度/亮度/暖土色（见阶段 3 第 9 步）；
- 输出 `final/<asset>.png`；**不要**烘焙地面/投影/草地。

## 7. 阶段 5：导入页锚定

1. 打开静态资源导入页，载入 PNG；
2. 设置 `footprint = W×H`、分类、阻挡；
3. 用旧模式：宽度/高度拉伸、左右侧手柄、图片偏移；
4. 锚点放在图片地基的**左/前/右**三个实际角（参考图绿点）；
5. `anchor_height = 1.0`（最多 ±0.15 做微调）；
6. 勾选“显示结果”，确认地基三点贴住占地、屋顶高度正确；
7. 保存。

## 8. 阶段 6：地图 45° 验收（是否突兀）

把新资产放回 `level_1_village` 或 `Level_1_new` 的实际位置，和邻居一起看：

- [ ] 地基左/右坡与占地参考差 ≤10%；
- [ ] 屋顶高度与同占地邻居一致（目标高度表）；
- [ ] 墙面竖直，不是等距俯视；
- [ ] 没有地面底座/草地/泥地/石台，阴影由引擎加；
- [ ] 茅草/石基/木构的颜色、饱和度、描边与邻居同一家族；
- [ ] 45° 无悬空/穿地/明显拉伸；遮挡、阴影正常；
- [ ] 建筑在整张地图里的相对大小不突兀（和门、树、邻居比）；
- [ ] 俯视 GridView 的占地/阻挡正确。

不通过时：

- 地基问题 → 回阶段 3（纹理锁回），不要加高度；
- 风格问题 → 换 Seedream 的 style ref/seed，或调色；
- 比例问题 → 回阶段 0/1 改线稿高度/占地。

## 9. 文件与命名约定

```text
Assets/Generated/GridAtlas/<batch>/
  ref/<asset>_ref.png          # 参考图/线稿
  seedream/raw/<asset>_seed<n>.png
  seedream/final/<asset>.png   # 去背/裁切/调色后的最终纹理
  rejected/<asset>_seed<n>.png # 不合格候选
```

- 每个资产的线稿、Seedream 候选、final、拒绝图分开；
- 同名 asset 只保留一个 final；旧素材在验收通过前不覆盖；
- `GridData/static_assets/defs/<asset>.tres` 与 `catalog.tres` 在验收通过后更新。

## 10. 批量与风格一致性

- 同一批（如贫村民居 5 款）共用：同一套线稿模板、同一张 style ref、同一 Seedream 模型、同一 seed 家族、同一提示词模板；
- 每个占地只做一套参考图；新建筑先套对应占地的参考，再画线稿；
- 每批先做 **1 张样片**，在真实地图里验收；通过后按同一流程批量；
- 每张 final 都与同批 2 张邻居并排截图，确认没有“混入另一个画风”；
- 不通过就回阶段 3/4，不要用运行时高度滑杆掩盖。

## 11. 判定树

```text
有 45° 参考/线稿？
├─ 有 → Seedream 上色 → 抠图/裁切 → 旧模式导入（art_size/lift/offset 手调）→ 地图验收
└─ 没有 → 先做 45° 参考/线稿，再走上面；不要靠运行时拉伸硬对三个地基角
```

  原生 **4.24×2.99**，底面斜率 **0.578（≈35.3°）**；按 `k=0.707/0.578=1.22` 拉高后 **4.24×3.66**，
  底面贴合 45°，比当前 4.74 低 23%。说明先用低矮源图抵消 1.3 的抬高是可行的；批量时每张按实测
  斜率算 k，不用固定 1.3。截图 `截图/45度预补偿-药铺.png`、`截图/45度预补偿-药铺-导入页.png`。
  后续两档试验反而更高：`0.50 宽` → 源 4.24×3.35、s=0.562、k=1.26、最终 4.21；`1.6 倍宽` →
  源 4.24×3.13、s=0.479、k=1.48、最终 4.62。原因是文字“更矮”同时改变了画面宽度和底面斜率，
  最终高度 `art_w × (h/w) × (0.707/s)` 不降反升。结论：提前量不能只靠提示词数字，必须量 clean 图的
  `h/w` 和 `s` 后选图，或用白模锁定宽高；截图 `截图/45度预补偿-三档.png`。
- **后续生成**：继续用 45° 参考 `Assets/Generated/GridAtlas/grid_ref_45/*_45deg`；AI 仍会压到 30°，
  必须预留 1.3，或走 ControlNet/3D。`grid_ref/*_30deg` 只作为 30° 实验的历史。
- **历史备份**：45° + 1.3 的 def/catalog 在 `%TEMP%/gridatlas_ai45_rebuild3/`（当前 def 就是从它恢复的）；
  30° 高瘦 defs 在 `%TEMP%/gridatlas_30tall_defs/`。
- **取舍**：45° + 1.3 会让房子比原图高约 30%，但网格/视角符合你的要求；如果不接受变高，只能 30° 或 3D。
- **验收截图**：`截图/导入页-45度-当前.png`、`截图/AI-45度-当前.png`；游戏端 `example/grid_atlas_demo.tscn`
  与编辑器渲染模式共用同一套 45° 投影，均已跑通、无脚本报错。
- **旧模式限制**：底边是一条斜线，不能同时精确命中占地的左/前/右三个角；非正方形占地的前角可能需要
  `art_offset` 微调。要三个角都精确贴合，需要重画底面或 3D，不要靠运行时硬拉。
- 历史记录：第 3/5/11 节的三点锚定、整图网格锁回、3D 体块都是已否决的尝试；当前以本节为准。

## 13. 这套流程为什么能复用

- **几何模板按占地复用**：2×2/3×3/3×4/4×3 各一套；新建筑只画线稿。
- **风格由 Seedream + 同村 style ref 锁定**：同一批共用参考，避免画风漂移。
- **纹理锁回保证地基/高度**：AI 图不再直接决定占地；线稿/3D 是唯一几何真相。
- **导入页锚定 + 地图验收**：把“看起来差不多”变成可检查的锚点/坡比/高度/阴影。
- **失败可回收**：Seedream 候选不合格放进 rejected，线稿/风格参考仍可复用；不会每张都从零开始。
