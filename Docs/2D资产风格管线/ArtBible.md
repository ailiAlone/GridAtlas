# GridAtlas 2D 资产 Art Bible（第一版）

> 适用：`level_1_content` 的村庄、森林、桥  
> 目的：给后续 AI 生成、素材筛选、引擎内调色提供同一套可执行的规则  
> 状态：第一版，随实际截图迭代

## 1. 世界与相机

| 项目 | 规则 |
|---|---|
| 投影 | 固定 45° 俯视，yaw 135°，pitch 45° |
| 相机 | 正交感优先；不混用其他轴测角度 |
| 像素密度 | 以游戏内 ppm 为准；资产按“格”定义尺寸 |
| 高度 | `height_scale = 2.0`（level_1_content 当前配置） |
| 光照方位 | `light_azimuth = 150°` |
| 光照高度 | `light_elevation = 35°` |
| 阴影 | 偏冷、低对比，不用纯黑；建筑/树底部有接触阴影；桥不额外画地面投影 |

## 3. 资产风格规则

### 3.1 统一规则

- **不要纯黑/纯白**：最暗用深棕 `#24170F`，最亮用暖白 `#F2E9D8`。
- **描边**：沿用现有 ChineseVillage 素材的深棕描边，宽度不要超过 2px（1024 图）。
- **对比**：建筑/树的高光不要比地形亮太多；树冠饱和度要比纯绿低一档。
- **细节频率**：树冠/木纹的细节不要比地形噪声密太多；远景树可以更简化。
- **接地**：建筑、树底部必须有接触阴影；禁止依靠 AI 图里的烘焙投影作为唯一接地。桥不额外画地面/水面投影，只保留桥体自身明暗。
- **视角**：所有资产按 45° 轴测绘制；不要出现侧面平视或俯视不一致。

### 3.2 引擎内统一

`sprite shader` 对所有立牌统一做：

- 饱和度 ×0.93；
- 轻微暖色 tint `(1.02, 0.99, 0.95)`；
- 脚底地形色的轻微环境反射（`u_ground_tint`）；
- 共享低频斑驳 + 0.012 细颗粒；
- 底部 AO/接触阴影（`runtime/asset_shadow.gd`：一张共享径向渐变纹理，每个立牌一次绘制，边缘平滑且省 draw call）；
- 45° 视图共享后处理（`style_overlay.gdshader`：轻微降饱和/对比、暖色调、暗角）。

这样建筑、树、桥即使来自不同批次，也会被拉到同一色阶。**真正的一致性靠同一个生成模型和同一套提示词/参考，而不是只靠后处理。**

## 4. 分类型规则

### 建筑（村庄）

- 来源：现有 ChineseVillage 素材（Doubao Seedream 5.0 Flash，pixel-art 12 色暖土色盘）。
- 主色：暖土黄墙、深灰瓦、深棕木结构。
- 屋顶不要纯黑；墙面不要纯白。
- 占地以 2×2 / 3×3 为主；民居、酒肆、铁匠铺、药铺、磨坊、谷仓保持同一套描边。
- 不强行生成新建筑，除非现有素材明显缺型。

### 树/森林

- 来源：**和建筑同一模型、同一套风格提示词**：Doubao Seedream 5.0 Flash + `普通瓦房.png` 作为风格参考；MiniMax 的矢量树已淘汰。
- 树种：阔叶、香樟、松树、竹丛；小树/竹子作为林下层次，不再使用矢量灌木/草丛。
- 叶色：橄榄绿/深绿为主，避免荧光绿；竹叶可以偏黄绿。
- 树干：暖棕，深色描边。
- 林地表：wasteland 暖褐色，允许绿色苔藓/草地斑块；不要整片纯绿。
- 树底部自带的小草/树根可以保留，但必须再叠加引擎接触阴影。
- 放置表现：每株植物随机 ±0.055×倍率 格的视觉位移、0.92~1.08 的尺寸偏置；只影响图片/树根草垫，不改变占格和阻挡。
- 个体差异：同一张树图按“资产 id + 格子坐标”派生稳定的个体差异——叶色偏黄/偏冷、整体大小 0.88~1.12、宽高比 0.90~1.10、树冠宽度/倾斜形变，约 1/3 水平镜像；不写存档，旧地图里的树也会立即生效。
- 植物倍率 1×~4×：占地/阻挡按整数倍（1×1/2×2/3×3/4×4），图片按 1/1.5/2/2.5 渐变；倍率与偏置随边车保存。
- 树根草垫自适应：
  - 地表着色器按树类物件脚底烘一张 `u_prop_ground` 遮罩（`MapRuntime.set_ground_props`），在树脚长一圈同色、同颗粒的草；
  - 立牌着色器 `u_soft_grass_base` 把贴图草垫的草色像素淡到约 15%，棕色的树干/树根保留；贴图草垫的硬边菱形由地形草接管。
- 草地纹理：橄榄底色 + 约 0.17 格一个“草窝”的屏幕竖直短叶（格内大幅抖动、两档密度留白），叶色从深橄榄过渡到黄绿，叶根有暗边；不使用大范围平滑渐变（那会读成流动的绿浆）。
- 水面流向：`Flow.CENTER` 视为静水；画了流向的水面叠加沿流向拉长的泡沫条纹、碎白和横波，溪流中要能一眼看出水在走；大水面没有流向时保持平静。
- 森林不是“树阵”：树冠要有大小变化、疏密团块、林间小径和空地。

### 桥

- 桥是**独立桥层**（`data/bridges_data.gd`，与地图同名 `.bridges.tres` 边车），不再放在静态资源里。
- 编辑器入口在“道路”面板：**独木桥 / 木桥 / 石桥** 三个按钮；左键拖一条直线跨过水面，右键删除。
- 拖动只沿主导轴吸附，**不能拐弯**：一条桥就是一个水平或垂直的直线跨度；斜拖会被吸附成横/竖，不会生成 L 形。
- 一条桥由两个 **1×1 桥座**（陆地）和中间**桥身**（水面，至少 1 格，长度不限）组成；拖动两端就是两个桥座，桥身全部格必须是水。桥面宽度 1 格；不能穿山、压静态物件或与已有桥重叠。
- 桥体视觉全部由 `runtime/procedural_bridge.gd` 按“类型 + 起终点”现场生成：
  - 独木桥：削平顶面的圆木、树皮、年轮、桥头石枕；
  - 木桥：木板、方柱栏杆、侧梁、木踏步、入水木桩；
  - 石桥：低石板桥面 + 两根石墩 + 实心石护栏 + 石踏步；没有拱。
- A*：桥线经过的格子覆盖地形代价，`surface_cost = 0.6`，深水也可通行；`MapRuntime.surface_z()` 返回桥面高度，游戏 demo 的角色会真正站在桥面上。
- 桥面只是 1 格宽，和静态资源一样参与占格/撤销/保存，但没有静态 PNG、没有 3×1/4×1/1×4 变体。

## 5. 当前实现状态

- 村庄：复用现有 ChineseVillage 素材，并补了点缀小树。
- 森林：Doubao Seedream 5.0 Flash 生成阔叶/香樟/松/竹，使用 `普通瓦房.png` 做风格参考；透明背景 PNG，已裁切/去白边。
- 桥：独立桥层 `BridgesData`（`level_1_content.bridges.tres`），道路面板三种类型；`level_1_content` 当前是木桥 `(29,35)→(32,35)`。
- 统一：sprite shader 饱和度/暖色/地形反射/斑驳/接触阴影；45° 视图共享后处理。
- 已知不足：shader 地形与像素风资产仍是两种媒介；桥仍是矢量平涂；桥面高度覆盖已在 demo 实现（编辑器 45° 预览不使用 A*）；森林还可以更密。
