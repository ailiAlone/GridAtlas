# GridAtlas 二期优化

定位：本工具的产出是**数据（.tres 地图）、场景与着色器**，不是图片。
"导出 PNG"一类出图功能不在目标内（调试截图用 `--shot` 已够用）。

一期已完成：陆地/水域/道路/流向/高程编辑、程序化成品渲染（俯视 + 斜角）、
渲染配置面板与 `.look.tres` 持久化、撤销/重做、地形雕刻（抬升/压低/平滑/展平）、
山体岩石/积雪着色。

## P1 着色器参数化：岩石/雪线阈值 + 坡面光照方向

- 现状：坡度 0.52–1.05 露岩、雪线 = 最大高程 × 0.62、光方向固定左上
  （`normalize(-0.62, -0.62, 0.48)`），三处均为硬编码。
- 目标：三者进渲染配置面板（滑条），随 `.look.tres` 持久化。
- 理由：着色器是交付物，硬编码阈值只适配当前这张图，换一张地势不同的图
  就得回来改代码。

## P2 斜角视角参数化

- 现状：斜角视图固定俯仰 0.93、固定方位。
- 目标：俯仰、方位旋转、距离（缩放）三个参数，面板可调。
- 理由：不同地图需要的展示角度不同；与 P1 互补（怎么看 / 看到什么）。

## P3 山体印章/生成器（数据线，缓做）

- 现状：堆山靠手刷，量大时繁琐。
- 目标：点击落一座带噪声起伏的山体/山脊，右键删除。
- 缓做理由：先用手刷积累实际使用感受，确认流程痛点后再做，避免过早优化。

## 低优先 / 观感打磨

- **斜角投影阴影**：目前斜角只有坡面明暗，没有山投山的影子。
- **斜角抗锯齿**：斜角视线遮挡边缘有锯齿，可加边缘软化。
- **高度场锐度（调研）**：CPU 端 5 点平滑核（1,4,6,4,1）限制了山的棱角，
  岩石/积雪只能靠坡度阈值"画"出来；可调研更锐的核或分级锐化，让雕刻直接出棱线。
- **潮汐参数拆分**（原 `RenderTool/render_settings.gd` 内 TODO）：沙地↔浅水
  与 浅↔深水 共用 `tide_frequency` / `tide_amplitude`，之后拆成两组独立参数。
  明确"以后再说"。

## 不做（已否决）

- **PNG 导出**：产出是数据/场景/着色器，不需要出图功能。
- **海岸锯齿柔化**：俯视渲染海岸已无可见锯齿（水深等值线方案已解决），无需再处理。
