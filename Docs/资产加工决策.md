## 2. 判定依据

### 2.1 alpha：这批用键控，不用 AI 抠图

- 本地 AI 抠图约 3–5 s/张，实心建筑可以，但镂空件会失败：E03 荆条篱笆的缝隙被 AI 保留成品红块（见 `Processed/_pilot/E03_ai.png`）。
- 品红键控把背景、柱脚紫影、镂空背景一次清掉；交付后复检 110 个文件：**0 个软 alpha、0 个残留品红像素（M>18）、0 个空图**。
- 结论：本批统一用品红键控；AI 抠图只保留给“非品红底”的后续批次。

## 3. 已执行的加工

- 输入：85 个 raw（true JPEG 或 true PNG）。
- 输出：**110 个 RGBA PNG** = 85 个 `__base` + 24 个 `__mirror_h` + 1 个 `__rotate_90`（E12 直段）。
- 目录：`Assets/ChineseVillage/Processed/delivery/<族>/`（按分类分文件夹：C_commercial /
  E_enclosure / F_farm / H_house / P_public / R_shrine / T_bridge / W_work / style_ref）；
  清单：`delivery/manifest.json`（`file` 字段含子文件夹）。
- 命名：`CV-<ID>__base.png` / `__mirror_h.png` / `__rotate_90.png`；同一设计不重复登记成新变体。
- manifest 字段：`canonical_id`（=id）、`transform`、`source_raw`、`source_bbox`、`baseline`、`baseline_out`、`pivot`、`content_size`、`art_size_px`、`margin_px`、`has_alpha`、`palette_colors`、`kernel`、`note`、`qa_status`。

### 3.1 参数

| 项 | 值 |
|---|---|
| 去底 | 品红键控：`min(R,B)-G > 45` 全透明；18–45 软边并去紫；<18 保留 |
| 透明边距 | 内容高的 6% |
| 下采样 | Lanczos3 到目标内容高，alpha 二次二值化 |
| 限色 | 每图 K-means，14–22 色，无抖动 |
| 尺寸 | 2×2 民居 200；3×3/3×2 220–230；1×1 小屋 140；小道具 100；E 模块 90–120；院门 140；桥 110–140 |
