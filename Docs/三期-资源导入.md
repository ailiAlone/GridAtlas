# 三期：资源导入与占地范围定义

> 状态：**数据定义、导入页、地图放置、掩码 A*、45° 立牌、横向/竖向两向均已实现。**
> 尚未实现：360° 方向美术变体、资源定义改动后的实例重校验、100–300 个物件的性能验收。
> 资产侧加工流程见 [资产加工方案.md](资产加工方案.md)。

## 0. 当前实现（2026-10-29）

- 导入页：`res://GridData/StaticAssetImportView.tscn`；编辑器里从资源库右侧「编辑」弹出，关闭后主编辑器自动重读 catalog。
  - 选择透明 PNG 并校验 alpha；45° 占地范围编辑器直接显示**裁切后的内容区**（与游戏端同一块图）；
  - 设置占地范围（`footprint`），在格子上点选真正阻挡 A* 的格子，其余格自动通行；
  - 网格按固定 135°/45° 投影显示；内容区由 alpha 自动裁出，保存到 `content_rect`；
  - 「宽度」控制立牌宽度；「高度拉伸」只改 Y；左右侧边中点可整侧抬高/压低（`art_lift`，最多 ±1 倍立牌高度）；右键拖动图片或填写「图片偏移」可整体移动（`art_offset`）；
  - 左右侧边中点可整侧抬高/压低（`art_lift`，最多 ±1 倍立牌高度）；宽度/高度拉伸/图片偏移控制立牌大小与位置；拖动期间冻结取景，松手后重新适配；
  - 保存/编辑/删除资源定义并更新 catalog。
- 数据：
  - `GridData/static_asset_def.gd`（`StaticAssetDef`）：id、名称、分类、层级、PNG 路径、内容区、立牌尺寸/拉伸/偏移、占地范围、阻挡模式与阻挡格；
  - `GridData/static_asset_catalog.gd`（路径索引）与 `static_asset_store.gd`（读写、运行时裁切纹理缓存、批量载入）；
  - `GridData/grid_projection.gd`（`GridProjection`）：固定 135°/45° 投影、占地中心、立牌矩形/四角的唯一定义，导入页、GridView/GamePreview、游戏端共用；
  - 定义文件：`GridData/static_assets/defs/*.tres`；索引：`GridData/static_assets/catalog.tres`。
- 语义：
  - `footprint` 是**占地范围**：放置预览、越界、重叠、右键删除都用它；
  - `blocking_mode` + `blocking_cells` 是**实际阻挡**：只有这些格写进 A*；
  - 门洞 = 占地范围减去阻挡格，数据层保持可通行。
- 地图侧：
  - `PropsData` 使用三个平行数组：`asset_ids / rots / cells`；`rots[i]` = 0（横向）/ 1（竖向）；
  - 实例存 **资源 id + 占地左上角锚点 + 方向 + 植物倍率/视觉偏置**；占地与阻挡格每次从定义解析，不重复存档；
  - 方向只有横向/竖向：竖向交换占地宽高（3×1 ↔ 1×3），阻挡格按 90° 矩阵转换；45° 立牌保持直立正面，但贴图**水平镜像**、左右 `art_lift` 换边、`art_offset.x` 取反；
  - 物件面板“资源库”上方有「横向 / 竖向」待放方向按钮；鼠标悬停在已放资源上按 **R** 原地旋转（绕占地中心，越界/重叠会拒绝），鼠标不在资源上按 R 只切换待放方向；旋转进入撤销/重做；
  - 物件面板资源库按类型分成建筑 / 树木 / 道具 / 门 / 栅栏 / 其他小节；植物选中后还可调 1×~4× 倍率；内置物件与立牌缩放滑条已移除；
  - 放置锚点按占地范围居中（3×1 鼠标格在中间，2×2 在左上角），与 `GridView` 的 ghost 共用 `PropsData.anchor_for()`；
  - `GridView` 的 ghost 画旋转后的占地范围、红/绿阻挡掩码和半透明 PNG；已放实例显示占地框、缩略图和门柱标记；
  - `MapRuntime.apply_props()` 只阻挡 `blocking_cells_at()` 返回的实际阻挡格；
  - 45° `GamePreview` 与 `example/grid_atlas_demo.tscn` 使用同一套 `content_rect` / `art_size` / `art_lift` / `art_offset`；脚底取旋转后占地范围的中心；立牌矩形由 `GridProjection.art_rect()` 给出，和导入页的占地编辑器共用同一套锚点；
  - 主编辑器选中/待放资源时，左上 45° 小预览和渲染模式大视图会叠画该资源的占地网格（红/绿格 + local 坐标）；小预览在鼠标悬停时额外画待放实例的 ghost 网格，公式和 GridView 落点一致；
  - 立牌（`example/actor_card.gd`）必须是 **Node2D**，不能用 Control：Control 的 `position` 会被 `gui/common/snap_controls_to_pixels`（项目默认开）吸附到整数；立牌挂在按 ppm 缩放的 `Actors` 下，等于把每个实例吸附到整格，成排同类建筑会随机偏半格、看起来"无规律交错"。改为 Node2D + `draw_rect` 自绘后落点像素级精确；
  - 旧边车的 `kinds/cells/scales` 内置物件格式已不支持：载入时 `sanitize()` 清空没有 `asset_ids` 的实例。

## 1. 边界：GridAtlas 不负责抠图

- GridAtlas 只消费**透明背景 PNG（RGBA）**。
- 抠图、去背景、品红转 alpha、AI matting 全部属于**外部资产生产工具/流程**，不是 GridAtlas 的功能。
- 导入器只检查 alpha：没有 alpha 就提示并拒绝，不调用任何抠图服务，也不生成处理后的图片。
- 资产提供方必须交付已经透明、已经裁好内容区的 PNG；导入页只记录 `content_rect`，不写裁切文件。

## 2. 数据模型

### 2.1 资源定义（`StaticAssetDef`）

```text
StaticAssetDef:
  id: StringName                 稳定标识，不重用
  display_name: String
  category: StringName           prop / building / gate / fence / bridge / tree / other
  tier: int                      同分类内的排序
  texture_path: String           指向 Assets/ 下的透明 PNG
  content_rect: Rect2i           非透明内容区；运行时在内存里裁切
  art_size: Vector2              立牌在屏幕上的宽高（格）
  art_lift: Vector2              左/右整侧抬升比例（占立牌高度）
  art_offset: Vector2            相对占地中心的屏幕偏移（格）
  footprint: Vector2i            占地范围尺寸（左上角锚点为实例数据）
  blocking_mode: int             ALL / NONE / MASK
  blocking_cells: Array[Vector2i] MASK 下的实际阻挡格（相对占地左上角）
```

### 2.2 地图实例（`PropsData`，`.props.tres` 边车）

```text
asset_ids[i]  资源定义 id
rots[i]       0=横向 / 1=竖向
cells[2i]     旋转后占地范围的左上角 x
cells[2i+1]   旋转后占地范围的左上角 y
```

没有 `kinds`、`scales`、`variants`。旧边车如果没有 `asset_ids`，载入时整体清空。
占地范围、阻挡格、立牌参数都从资源定义读取，修改定义后所有实例共享新值。

### 2.3 左右侧拉伸（旧模式）

```text
art_size = Vector2(宽, 高)      # 立牌在屏幕上的尺寸（格，不按俯角压缩）
art_lift = Vector2(左, 右)      # 左/右整侧抬升比例（占立牌高度）；正数=抬高
art_offset = Vector2(x, y)      # 相对占地中心的屏幕偏移（格）
```

- **原理**：图片保持原比例直立，左右两侧可以各自抬高/压低，底边变成一条斜线；整张图做垂直剪切，竖墙保持竖直，不做仿射/透视变形。
- **限制**：只有左右两个自由度，最多让底边贴着一条斜线；不能同时命中占地的左/前/右三个角。非正方形占地的前角通常需要 `art_offset` 微调，底面可能轻微浮空。
- **导入页**：拖动左右侧边中点手柄改 `art_lift`；宽度/高度拉伸改 `art_size`；右键拖图或填写图片偏移改 `art_offset`。拖动期间冻结取景，松手后重新适配。
- **竖向实例**（`rots=1`）：贴图水平镜像，左右 `art_lift` 换边，`art_offset.x` 取反。
- **截图**：旧模式截图见 `Docs/2D资产风格管线/截图/`；三点锚定截图已归档。

## 3. 流程

1. PNG 放进项目（`Assets/.../delivery/`），Godot 自动导入。
2. 打开导入页，选择 PNG；检查 alpha、自动裁出内容区。
3. 设置名称/分类/层级、占地范围、阻挡格；用宽度/高度拉伸、左右侧手柄、图片偏移把立牌调到占地范围上。
4. 保存为 `GridData/static_assets/defs/<id>.tres`，catalog 自动登记。
5. 资源库选中资源 → 地图点击放置；ghost 显示占地范围与阻挡掩码。
6. 保存地图时同时写 `<地图名>.props.tres`；45° 预览、A*、撤销/重做、改尺寸、重开都读取同一份数据。

## 4. 占地范围与阻挡

- 占地范围是**矩形**，用于放置碰撞、越界、重叠和右键删除；目前没有非矩形 footprint。
- 阻挡格是占地范围的子集：
  - `ALL`：整块占地阻挡；
  - `NONE`：整块可通行；
  - `MASK`：只阻挡 `blocking_cells`，门洞/桥面可通行。
- 放置碰撞按占地范围判定；A* 按阻挡格判定。两者故意分开，院门可以占地 3×1 而只有两根门柱挡路。
- 放置只校验地图边界与实例重叠，**不受地形限制**：建筑/桥可以放在水面、山体等任意地形上。
- 实例旋转 90° 时，占地宽高交换、阻挡格按矩阵转换；立牌贴图水平镜像，避免"同一张正面图"在竖向时方向错位。

- [x] 导入带 alpha 的 2×2 房：占地 2×2、全阻挡；能放置、45° 显示、存档重开。

- [x] 3×1 院门横竖切换：竖向占地 1×3、阻挡掩码一起转、门洞仍可通行、立牌水平镜像；越界/重叠拒绝、撤销/重做、存档往返均有自动测试。
- [x] 桥/建筑可直接放在水面上；放置与旋转只校验边界和实例重叠，不受水面/山体等地形限制。

## 7. 已知取舍

- 只用一张正面图：竖向靠水平镜像，不生成 90° 美术变体；建筑背面/侧面没有专门素材。
- 资源定义修改后不回溯校验已放实例的越界/重叠；需要手动移动或删除。
- 桥/木栈道可放在水面上；水面不会修改桥的地表高度，跨水立牌的脚底高度仍取占地中心地形。
- 立牌按占地中心取一个地表高度，跨坡建筑可能有一侧悬空；后续可做多脚采样或"占地压平"。
- 左右侧拉伸只做垂直剪切：底边是一条斜线，不能同时精确命中占地的左/前/右三个角；非正方形占地的前角可能需要 `art_offset` 微调。要三个角都精确贴合，需要重画底面或改用 3D/四点方案，不要靠运行时硬拉。
- 导入页只接受项目内可 `load()` 的 PNG 路径；不做运行时下载/复制。
