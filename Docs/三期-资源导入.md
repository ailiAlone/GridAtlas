## 0. 当前实现（2026-10-28）

- 导入页：`res://GridData/StaticAssestImportView.tscn`；编辑器里从资源库右侧「编辑」弹出，关闭后主编辑器自动重读 catalog。
  - 选择透明 PNG、校验 alpha；45° 占地范围编辑器直接显示**裁切后的内容区**（与游戏端同一块图），不再单独放大图；
  - 设置占地范围（`footprint`）；
  - 在格子上点选实际阻挡格（门柱/墙体），其余格自动视为通行；
  - 网格按固定 135°/45° 投影显示；内容区自动从 alpha 裁切，保存时写入 `content_rect`；
  - 「宽度」滑条控制立牌宽度；「高度拉伸」只改 Y，调高变瘦、调矮变宽；下方实时显示实际尺寸；
	左右侧边中点可整侧抬高/压低（`art_lift`），侧向拉伸图片去对齐网格；
	右键拖动图片或填写「图片偏移」可整体移动（`art_offset`）；
  - 保存/编辑/删除资源定义，更新 catalog；编辑旧定义时保留已存的 `pivot`。
- 数据：
  - `GridData/static_asset_def.gd`（`StaticAssetDef`）：id、名称、分类、PNG、内容区、立牌尺寸、`art_lift`、`art_offset`、pivot、footprint、blocking_mode、blocking_cells；
  - `GridData/static_asset_catalog.gd`（路径索引）与 `static_asset_store.gd`（读写 + 运行时裁切纹理缓存）；
  - 定义文件：`GridData/static_assets/defs/*.tres`；索引：`GridData/static_assets/catalog.tres`。
- 语义：
  - `footprint` 是**占地范围**：放置预览、越界、重叠、右键删除都用它；
  - `blocking_mode` + `blocking_cells` 是**实际阻挡**：只把这些格写进 A*；
  - 门洞 = `footprint` 减去 `blocking_cells`，在数据层保持可通行。
- 地图侧（第二阶段，已接入）：
  - `PropsData` 使用 `asset_ids / cells / scales / rots` 四个平行数组；`rots[i]` = 0（横向）/ 1（竖向）。`kinds` 只是旧边车反序列化占位，载入时 `ensure_compat()` 丢弃所有没有 asset_ids 的旧内置实例；
  - 地图实例只存 **资源 id + 左上角锚点 + 缩放 + 方向**；新放置固定缩放 1.0（旧实例保留原值），占地与阻挡格每次从定义解析，不重复存档；
  - 方向只有**横向 / 竖向**两种：竖向交换占地范围宽高（3×1 ↔ 1×3），阻挡格按 90° 矩阵转换；45° 立牌保持直立正面，但贴图**水平镜像**、左右 `art_lift` 换边、`art_offset.x` 取反，让画面也跟着换方向；
  - 物件面板“资源库”上方有**待放方向**「横向 / 竖向」两个按钮，控制下一次放置；鼠标悬停在已放资源上按 **R** 在横/竖之间切换（绕占地中心；越界/压水/与其它实例重叠会拒绝），鼠标不在资源上按 R 只切换待放置方向；切换进入撤销/重做；
  - 物件面板只保留“资源库”动态按钮（按分类/层级排序）+ “刷新” + “编辑”（弹出导入页）；内置物件按钮和立牌缩放滑条已移除，新放置只来自资源库；
  - 资源放置锚点按占地范围居中（3×1 鼠标格在中间，2×2 在左上角），与 `GridView` 的 ghost 使用同一个 `PropsData.anchor_for()`；
  - `GridView` 资源 ghost 画旋转后的占地范围 + 红/绿阻挡掩码 + 半透明 PNG；已放实例在俯视图里显示占地框、缩略图和门柱标记；
  - `MapRuntime.apply_props()` 只阻挡 `blocking_cells_at()` 返回的实际阻挡格；内置物件运行路径已完全移除；
  - 45° `GamePreview` 与 `example/grid_atlas_demo.tscn` 都会生成资源立牌：贴图按 `content_rect` 裁切，`art_size` 决定大小，`art_lift` 通过 `actor_sprite.gdshader` 的剪切采样实现左右整侧拉伸，`art_offset` 只移动画面、不改脚底与遮挡判定；脚底用旋转后占地范围的中心；demo 无物件边车时显示空地图，不再生成随机林；
  - 放置/删除/清空/旋转/撤销/重做/改尺寸/存档重开都包含 `asset_ids` 与 `rots`，已用自动测试覆盖；
  - 内置物件运行路径已完全移除：旧边车里的 `kinds`/cells/scales 实例在 `ensure_compat()` 时丢弃，不再渲染、阻挡或显示。
- 尚未接入：`pivot` 目前只存档（导入页不再暴露，编辑旧定义时保留原值；立牌锚点固定为 footprint 中心 + `art_offset`）；360° 方向美术变体 / 建筑背面（当前只有“横向原图”和“竖向水平镜像”两种）；资源定义改动后对已放实例的重叠/越界重校验；桥/木栈道的水面放置规则（当前仍统一禁止压水）。

## 1. 边界：GridAtlas 不负责抠图

- GridAtlas 只消费**透明背景 PNG（RGBA）**。
- 抠图、去背景、品红转 alpha、AI matting 全部属于**外部资产生产工具/流程**，不是 GridAtlas 的功能。
- 导入器只做 `has_alpha` 校验：没有 alpha 就提示并拒绝，不调用任何抠图服务，也不生成处理后的图片。
- 资产提供方必须交付已经透明、已经裁好内容区的 PNG。
- 本地 AI 抠图 skill 属于资产生产侧；不要把它接进 GridAtlas 的导入按钮。

## 2. 目标

让用户把一个透明 PNG 变成一个**可重复使用的资源定义**，并能在网格里放置：

1. 导入 PNG，校验 alpha。
2. 定义资源：名称、分类、层级、内容区、艺术尺寸、脚底锚点、占地范围、阻挡/通行、变体、方向。
3. 保存到资产目录（catalog）。
4. 在物件面板选中，点击地图放置实例。
5. 实例写入地图边车，参与阻挡/A*、45° 渲染、遮挡、存档、撤销。

## 3. 关键原则

### 3.1 导入和放置分开

- **导入**是资产库的一次性动作，不绑定地图坐标。
- **放置**是地图实例动作，点击格子只放置已经定义好的资源。
- 可提供“导入并放置”快捷流程：导入完成后自动选中新资源，下一次点击地图落下；数据上仍是两步。

### 3.2 程序只建议，不替用户决定占地范围

程序能自动做：读文件格式/尺寸、检测 alpha、裁内容区、生成缩略图。  
程序可以建议：按分类预设推荐占地、默认脚底锚点、默认艺术高度。  
必须人工确认：语义类型、精确占地范围、阻挡/通行、门朝向、悬挑、旋转、地形限制。

### 3.3 三层分离

| 层 | 含义 | 存在哪里 |
|---|---|---|
| Footprint | 占哪些格 | 资源定义（矩形或 cell mask） |
| Art size + pivot | 贴图多大、脚底/base 对哪里 | 资源定义 |
| Blocking / pass | 哪些格挡 A*，哪些格可通行 | 资源定义（blocking mask / pass cells） |

房子通常三层一致；牌坊、门楼、桥、院门通常不一致，必须分开建模。

## 4. 用户流程

1. 点击“导入资源”或把 PNG 拖进窗口。
2. 校验 alpha；无 alpha → 明确报错，不处理。
3. 预览：45° 占地范围编辑器直接显示自动裁切后的内容区（不再单独放大图）。
4. 资源定义：
   - 名称、分类、层级（T0–T5）
   - 内容区（content rect）
   - 艺术尺寸（world cells）
   - 脚底锚点（bottom-center / 自定义偏移）
   - 占地范围：矩形预设（1×1、2×2、3×3、3×1）或画格掩码
   - 阻挡：全挡 / 不挡 / 指定可通行格
   - 变体：同一资源多张图，共享占地范围与锚点
   - 方向：水平/垂直、翻转、旋转（按需）
   - 图标：先用缩略图，后续可换手绘俯视图标
5. 保存到 catalog；处理后的 PNG 复制进项目资产目录。
6. 物件面板选中 → 地图点击放置 → ghost 显示完整占地范围 → 越界/重叠/地形校验 → 写入边车。
7. 45° 预览、遮挡、A*、存档重开、撤销验证。

## 5. 数据模型（建议）

### 5.1 资源定义

```text
PropDef:
  id: stable string or int (never reused)
  pack_id: string
  name: string
  category: string
  tier: int
  texture_path: string
  content_rect: Rect2i
  art_size: Vector2 (cells)
  art_lift: Vector2 (左侧/右侧整侧抬升量，占 art 高度比例)
  art_offset: Vector2 (相对 footprint 中心的屏幕格偏移，x 右 / y 下)
  pivot: Vector2 (normalized, bottom-center default)
  footprint: Rect2i (bounding box)
  footprint_cells: Array[Vector2i] (optional mask)
  blocking_cells: Array[Vector2i] or mode
  pass_cells: Array[Vector2i] (gates/bridges)
  variants: Array[texture_path / content_rect / art_size]
  icon_path: string
  has_alpha: bool
```

### 5.2 地图实例

继续沿用现有紧凑数组，追加可选字段（第二阶段已实现 `asset_ids` / `rots`）：

```text
kinds[i]      旧边车反序列化占位；载入即丢弃，不再使用
asset_ids[i]  资源定义 id（StringName）；有效实例
rots[i]       实例方向 0=横向 / 1=竖向（图片水平镜像）；旧数据默认 0
cells[2i]     旋转后占地范围的左上角锚点
scales[i]     实例倍率
variants[i]   可选，旧数据回退 hash 变体（未实现）
flips[i]      可选（未实现）
```

旧边车必须能加载；新字段缺省时使用旧行为。

### 5.3 ID 与素材包

- 不要让新资源直接复用或重排 Tiny Swords 的 0–8。
- 推荐 `PropSet`/`AssetPack`：一个包一套 ID、图标、尺寸、占地；地图边车记录 pack id。
- 如果没有 pack，至少保证 ID 只追加、不重排、不重用；删除资源时保留墓碑 ID。

## 7. 静态场景约束

现有约束是“容器静态包含内容，切换只做显隐”。资产库列表和占地范围编辑器需要动态内容，无法完全静态。  
建议只开两个例外：

- 资产列表项可以按 catalog 动态生成/回收。
- 占地范围编辑器的格子可以按网格尺寸动态生成。

主视图（GridView / GamePreview / GamePreviewMini / GridViewMini）仍然只做显隐切换。
